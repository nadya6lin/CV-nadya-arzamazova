# Arzamazova.CV — GitHub Pages

Это готовая версия сайта для GitHub Pages. Визуальная разметка Tilda сохранена; оригинальные Tilda CSS/JS и изображения подключаются с Tilda CDN, поэтому их не нужно скачивать вручную.

## Структура

- `index.html` — сама страница. **Здесь меняется текст, ссылки и содержимое блоков.**
- `css/custom.css` — твои дополнительные стили.
- `js/custom.js` — твой дополнительный JavaScript.
- `.nojekyll` — нужен для корректной публикации статических файлов.
- `CONTENT-MAP.md` — подсказка, где искать основные части сайта.
- `backup/` — исходный HTML на случай, если что-то случайно сломается.

## Как опубликовать

1. Создай на GitHub новый репозиторий с именем `arzamazova`.
2. Загрузить нужно **содержимое этой папки**, а не сам ZIP-файл. В корне репозитория должны лежать `index.html`, папки `css`, `js` и т.д.
3. GitHub → **Settings → Pages**.
4. **Source: Deploy from a branch**.
5. **Branch: main**, папка **/(root)** → **Save**.
6. Через некоторое время сайт будет доступен по адресу `https://ТВОЙ-USERNAME.github.io/arzamazova/`.

## Как редактировать

### Текст
Открой `index.html` → `Edit this file` → `Cmd/Ctrl + F` → найди нужную фразу → измени её → `Commit changes`.

### Цвета, размеры, отступы
Открывай `css/custom.css`. Свои правила добавляй между комментариями `YOUR CHANGES START/END`.

### JavaScript
Открывай `js/custom.js`. Ничего туда не добавляй, если не понимаешь, зачем это нужно: основной Tilda JavaScript уже работает в `index.html`.

## Важно

Эта версия использует ресурсы Tilda CDN. Это сделано специально, чтобы сохранить внешний вид исходной страницы без огромной папки из служебных файлов Tilda. Если позже захочешь полностью отвязать сайт от Tilda, нужно будет отдельно скачать и локально сохранить все CSS/JS/изображения/шрифты.

## Если сайт не обновился

После Commit GitHub Pages иногда требуется несколько минут. Обнови страницу через `Cmd + Shift + R`.
