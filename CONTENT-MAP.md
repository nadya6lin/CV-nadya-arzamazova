# Где что менять

Основной файл — `index.html`. Это большой экспорт Tilda, поэтому **не пугайся его размера**. Для поиска используй `Cmd + F`.

## Основные якоря страницы

- `#about` — блок «Обо мне»
- `#edu` — образование
- `#skills` — навыки
- `#portf` — портфолио
- `#contacts` — контакты

## Самый безопасный способ редактирования

1. Открой сайт.
2. Скопируй точную фразу, которую хочешь изменить.
3. В GitHub открой `index.html`.
4. `Cmd + F` → вставь фразу.
5. Меняй только текст внутри соответствующего HTML-блока.
6. Нажми **Commit changes**.
7. Проверь сайт.

## Чего пока не трогать

Не удаляй `<script>`, `<link>`, блоки с `t396`, `tilda`, `t-records`, `data-record-type`, а также длинные JavaScript-блоки внизу страницы. Они отвечают за работу экспортированных блоков.

Для визуальных правок используй `css/custom.css` — это безопаснее.
